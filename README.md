# 🎮 РРП 3.0 — сайт ролевого проекта в Roblox

Сайт для набора в команду RP-проекта: анкеты на **Модератора** и **Администрацию**,
правила проекта, статус заявки с ответом администрации и закрытая админ-панель.

## 📄 Страницы

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная — приветствие, направления набора |
| `anketa.html` | Анкеты: Модератор (14+), Администрация (15+) |
| `status.html` | Игрок вводит код/ник и видит статус + ответ администрации |
| `rules.html` | Правила проекта и система наказаний |
| `updates.html` | История обновлений сайта (чейнджлог) |
| `admin.html` | Панель администрации (вход по паролю) |

## ⚙️ Возрастные требования

- 🛡️ **Модератор** — от 14 лет (иногда исключение с 13 лет, с обоснованием)
- 👑 **Администрация** — от 15 лет

## ☁️ Подключение Supabase (общая база заявок)

Без настройки сайт работает в **локальном режиме** — заявки видны только с того
устройства, где их отправили. Чтобы заявки и ответы были общими:

1. Создай бесплатный проект на [supabase.com](https://supabase.com)
2. Открой **SQL Editor** → вставь содержимое `supabase-setup.sql` → **Run**
3. В **Project Settings → API** скопируй:
   - **Project URL** → вставь в `SUPABASE_URL`
   - **anon public key** → вставь в `SUPABASE_ANON_KEY`
4. Вставь оба значения в файл `supabase-config.js`

> Ключ `anon public` предназначен для клиентских приложений и считается
> публичным — его можно хранить в коде. Доступ к данным защищён политиками RLS.

## 🔑 Админ-панель

- Ссылка: `admin.html`
- Пароль по умолчанию: `admin123`
- **Смени пароль сразу после первого входа** (кнопка «Сменить пароль»)
- В панели: фильтры, сортировка, поиск, шаблоны ответов, экспорт JSON

## 🧰 Технологии

Чистые HTML / CSS / JavaScript, без сборки и зависимостей.
Хранилище — Supabase (облако) с автоматическим откатом на `localStorage`.

## 📦 Локальный запуск

```bash
python -m http.server 8765
# затем открой http://localhost:8765/index.html
```
